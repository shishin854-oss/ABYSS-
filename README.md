
# ABYSS

Site oficial da comunidade ABYSS no Discord.

## Arquivos

- index.html
- style.css
- script.js

## Publicação

1. Crie um repositório no GitHub.
2. Envie os três arquivos.
3. Entre em Settings.
4. Acesse Pages.
5. Selecione Deploy from a branch.
6. Selecione main e /(root).
7. Clique em Save.
